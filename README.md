# McDonald's Sales & Profitability Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** designed to analyze McDonald's sales performance, profitability, orders, products, stores, and customer behavior. It brings key business metrics together in one place to support data-driven decision-making.

## Dashboard Features

- **Key performance indicators (KPIs):** Total revenue, gross sales, profit, cost, orders, quantity sold, and number of stores.
- **Sales trends:** Revenue trends over time.
- **Product performance:** Compare revenue, profit, cost, and quantity sold across products and categories.
- **Order analysis:** Explore order distribution by order type.
- **Store analysis:** Compare performance across store types.
- **Customer analysis:** Filter results by customer type and explore differences between customer groups.
- **Interactive filters:** Customer type, city, region, quarter, payment method, food type, and day of the week.

## Tools & Technologies

- **Microsoft Power BI Desktop** — dashboard development and data visualization
- **DAX (Data Analysis Expressions)** — measures and KPI calculations
- **Data modeling** — organized analytical model, including a date table

## Metrics & Calculations

The report includes measures for:

- Total revenue, gross sales, total cost, and total profit
- Total orders, customers, quantity sold, products, and stores
- Average order value and average order profit
- Profit margin and cost as a percentage of revenue
- Discount amount, discounted orders, and discount impact
- New versus returning customer metrics
- Revenue and profit comparisons by product and store

The dashboard uses DAX measures to calculate these metrics dynamically based on the selected filters.

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it in **Microsoft Power BI Desktop**.
3. Wait for the report to load.
4. Use the slicers to filter the dashboard by customer type, city, region, quarter, payment method, food type, or day.
5. Select chart elements to cross-filter other visuals and explore performance in more detail.
